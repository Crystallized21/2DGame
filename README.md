# Blue Boy Adventure

This project is based on RyiSnow's Tutorial: [Tutorial Link](https://www.youtube.com/watch?v=om59cwR7psI&list=PL_QPQmz5C6WUF-pOQDsbsKbaBZqXj4qSq)

## Description
This is an old-style 2D Pixel adventure RPG game, where you fight against enemies and bosses to get to the end of the game.
All while collecting coins, new faces, and exploring uneasy areas to collect items to aid you on your journey.

## Features

- 2D Pixel Art
- Many Maps
- Many Enemies
- Items and inventory system
- Dialogue system
- Save and Load system
- Bosses
- Cutscenes
- Music and Sound Effects
- Day and Night cycle

## What I've added to my own flavour.

I added new enemies, new items, and new maps using the knowledge I've gained from the tutorial.
These new additions help expand the game, making the game longer and more enjoyable.
All of this was done by myself, including designing the sprites and the maps.
